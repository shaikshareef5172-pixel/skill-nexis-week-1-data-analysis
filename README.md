
# Skill Nexus Week 1 – Data Analysis

## Project Title
Global Superstore 2016 Data Analysis

## Objective
The objective of this project is to analyze the Global Superstore 2016 dataset using Microsoft Excel and understand basic data analysis concepts.

## Tasks Completed
- Data cleaning
- Missing-value handling
- Duplicate checking
- Region-wise sales analysis
- Category-wise revenue analysis
- Mean, median and mode calculation
- Top 10 sales analysis
- Yearly sales trend
- Dashboard creation

## Tools Used
- Microsoft Excel
- Global Superstore 2016 Dataset

## Key Results
- Total Revenue: $12,642,501.91
- Average Sales: $246.49
- Median Sales: $85.05
- Mode Sales: $12.96
- Duplicate Rows: 0

## Project
This project was completed as part of Skill Nexus Week 1 Data Analysis training.
